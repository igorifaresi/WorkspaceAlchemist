# WorkspaceAlchemist

Using IPC and D3D11 process texture sharing to create a new kind of desktop environment. Instead of applications being like desert islands with no communication with other, WorkspaceAlchemist tries to change that bringing visual unix-like pipes, and an easy to use interface to make the connections. Everything, even the UI is being made from scratch using Odin. Work in progress.

## What I already have

- Applications being running in different processes trading messages with the central application.
- Applications sharing the D3D11 texture to the central.
- An almost fully function ImGUI.
- An build system.
